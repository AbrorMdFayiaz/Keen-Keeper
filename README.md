# 🫂 Keen-Keeper

> **Keen-Keeper is a virtual dashboard for friends.**

---

## 🛠️ Technologies Used

- ⚛️ **React**
- 🧭 **React-Router (Data Mode)**
- 📊 **Recharts**
- 🔔 **Toastify**
- 🎨 **React-icons**
- 🚀 **Netlify** — for deployment

---

## ✨ Features

- 👥 Keep track of our **close friends**
- 💬 **Interact** with friends
- 🕒 See all interactions in a **Timeline** page
- 📊 View **statistics of the interactions**
